# SpotZoom_Machine_Learning

## 项目概述

SpotZoom_Machine_Learning是一个综合性的光学成像与机器学习项目，包含从v1到v26的创新迭代，集成了自适应光学、数字孪生、模型预测控制等前沿技术。

## 项目结构

### 核心模块

1. **SpotZoom.py** - 主程序入口
   - 包含GUI界面、图像处理、相机控制等核心功能
   - 集成自适应光学控制、轨迹记录、诊断监控等模块

2. **innovation_frontier_v17-v26** - 前沿创新模块
   - 包含10个版本的创新实验模块
   - 每个模块包含配置类、结果类、核心处理函数

3. **support_modules** - 支撑模块
   - data_pipeline_orchestrator - 数据管道编排
   - adaptive_optics_controller - 自适应光学控制器
   - trajectory_recorder - 轨迹记录器

## 集成参考的开源项目

### 显微镜图像分析领域

1. **CellPose** - 通用细胞分割模型
   - 创新点：自监督预训练、实时推理优化
   
2. **StarDist** - 星形对象分割
   - 创新点：星形检测网络、几何感知损失函数

3. **napari** - 多维图像可视化框架
   - 创新点：插件系统架构、GPU加速渲染

### 状态空间模型领域

1. **Vision Mamba** - 视觉状态空间模型
   - 创新点：双向状态空间机制、线性时间复杂度

2. **MambaIR** - 图像恢复状态空间模型
   - 创新点：图像恢复专用状态空间建模

### 物理信息学习领域

1. **PINN** - 物理信息神经网络
   - 创新点：物理约束编码、PDE集成
