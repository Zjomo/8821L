Instructions

This CD contains the Manuals for the Acton Research Corporation SpectroPro 
Instruments and Accessories, as well as the Acton Research Corporation 
Catalogs and Technical Notes.

Insert the CD into your CD-ROM drive and choose Run from the Start Menu 
(Windows 9x or NT 4.0).
Note: If you have Autoplay configured, the menu program will start automatically.

Type d:\Acton_Info.exe  (where d: is the CD-ROM drive letter).

From the list on the left of the screen, scroll down to the name of the Manual 
desired and double click the title.  This will launch the Manual in Adobe Acrobat 
from which it can be viewed or printed.

If Adobe Acrobat is not installed on your system click the "INSTALL ADOBE 
ACROBAT" button and follow the onscreen instructions.

Acrobat Reader 5.0 system requirements 

Intel Pentium processor

Microsoft Windows 95 OSR 2.0, Windows 98 SE, 
Windows Millennium Edition, Windows NT 4.0 with 
Service Pack 5, Windows 2000, or Windows XP

64 MB of RAM

24 MB of available hard-disk space

CD-ROM Drive
