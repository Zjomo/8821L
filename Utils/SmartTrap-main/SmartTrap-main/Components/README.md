# Excel files with lists of the components needed for the different parts of the system

## ComponentList contains the following
 - List of the components needed for the optical tweezers instrument, based on the minitweezers design <http://tweezerslab.unipr.it/cgi-bin/home.pl>
 - List of components needed for the controller power supply.
 - List of the equipment needed to run the instrument, such as the host computer.
