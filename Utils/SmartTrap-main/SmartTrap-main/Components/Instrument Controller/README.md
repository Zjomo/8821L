## Boards

###  Microcontroller board
Hosts the arduino portenta H7 (not included in BOM). Besides this has only two connectors to connect the arduino and two to connect to other boards. The USB port on the arduino is used for communications with the host computer.

### Sensor board
Amplifies the signals from the various photosensors and hosts the analog digital converter used to sample these signals.

### Actuator board
Used to steer the motors of the instrument and to move the lasers.
