# SpotZoom 项目深度分析报告

## 一、项目概览

**SpotZoom** 是一个基于 **MRC（Mirror Reaction Control）主动激光束稳定系统**的自动准直项目。核心目标是通过"**检测 → 反馈 → 调整**"的闭环机制，利用电机驱动反射镜实时补偿激光束的位置偏移和角度偏移，实现高精度激光束自动对准。

项目编号为 **8821L**，硬件上使用两个 **8742 控制器** + 4 个 **8821L 压电电机**驱动两块镜片，加上 UCC 探测器（CCD 相机）构建 4 轴双镜闭环系统。

## 三、核心架构：分层设计

### 3.1 整体数据流

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 图像采集  │ -> │ 光斑检测  │ -> │ 偏差计算  │ -> │ 电机驱动  │ -> │ 闭环收敛  │
│ (Frame    │    │ (Detection│    │ (Error    │    │ (Motor    │    │ (Converge │
│  Source)  │    │  Layer)   │    │  Calc)    │    │  Control) │    │  Check)   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
       ↑                                                              │
       └──────────────────────────────────────────────────────────────┘
```

### 3.2 六层架构详解

| 层级           | 核心组件                                                     | 功能                                                         |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **图像采集层** | `ToupViewWindow`, `SimulatedFrameWindow`, `UCCFrameSource`, `FrameSourcePair` | 支持实机截屏/模拟图/UCC CCD相机 三种方式获取帧               |
| **检测层**     | `SpotYOLODetector`(YOLO), `SpotClassicDetector`(OpenCV), `SpotYOLOWorkerClient`(子进程) | 三种后端，自动优先级：YOLO → classic，含 sub-pixel、confidence 等增强 |
| **控制层**     | `SpotZoomController`（主控制器 ~12000 行）                   | 核心闭环逻辑：目标点(P1) → Z上移(P2) → Z下移(P3) → 收敛判据，含大量 v26-v57 的前沿门控策略 |
| **执行层**     | `ThorlabsXYStage`, `NewportXYStage`, `PicoMotor8742Controller`, `NewportMRC4MirrorStage`, `XPSZAxis` | 多品牌电机驱动，含 PID 控制器、自适应步长                    |
| **保护层**     | `RunLockFile`, `RunReporter`, `SafetyManager`                | 防并发锁、运行事件记录、安全检查                             |
| **策略层**     | `FourAxisController`, `PIDController`                        | 支持 z_scan_legacy（5轴）和 dual_detector_4axis（4轴）两种策略 |

### 3.3 SpotZoomController —— 核心控制器

主控制器是 [SpotZoomController](file:///e:/jupyter file/2_Optics/8821L/SpotZoom.py#L5813)，内部集成了约 **40+ 个 frontier 检测策略**（从 v17 到 v57），是系统中最大的类。核心运行流程：

1. **主检测链**：抓帧 → 预处理（可选 v7 去噪、v26 增强、多帧去噪）→ 主检测 → SAM2 精修 → v26 像差门控 → 光学质量门控 → 焦点评分 → 置信度门控 → 不确定性门控 → domain probe → 平滑
2. **多级恢复链**（主检测失败时按序尝试）：LodeSTAR → StarDist → memory recover → v27 wavelet → Kalman template → KLT 光流 → pyramid template → log-polar → phase correlation → ECC → CMC affine → ORB homography → temporal ensemble → buffered reuse → recovery scan

## 六、三种准直策略

### 策略 1：`z_scan_legacy`（传统5轴Z扫描）
```
P1（初始）→ Z上移 → P2 → XY对齐到P1 → Z下移 → P3 → XY对齐到P1 → 收敛判据
```
适用于 ToupView 显微镜成像模式。

### 策略 2：`dual_detector_4axis`（4轴双镜闭环）
```
Stage1 (镜1 x/y) 控制位置误差 (Detector1)
Stage2 (镜2 x/y) 控制角度误差 (Detector2)
```
- 控制律：`u1 = Kp1*e_pos + Ki1*∫e_pos + C12*e_ang`（双段解耦 PI 控制）
- 支持 4x4 灵敏度矩阵标定与耦合补偿

### 策略 3：`detector_comparison`（探测器效果对比）
```
支持 detector_primary / touview_verify / auto_switch 三种比较模式
加权融合探测器与 ToupView 两个源的结果
```
